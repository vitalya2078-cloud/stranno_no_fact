# «А что если…» — ролик от идеи до mp4

Владелец работает **только с Android-телефона**: всё, что нужно от него, — выбрать, прочитать, сгенерировать голос
на сайте ElevenLabs и прислать mp3. Отвечай по-русски, на «ты», просто. Не переходи к следующему этапу без его «ок».

`<P>` — папка ролика: `project/<slug>` (латиница, напр. `project/wifi-visible`). Шаблон — `template/` рядом с этим файлом.
Фирменный стиль и палитры — `project/BRAND.md` (решение владельца: **основной D, A — по необходимости**).

## Шаг 1. Идеи
Предложи **5 свежих** идей «А что если…» одной строкой-хуком + 1 строка «почему залетит».
- Избегай заезженного (владелец это всё видел): гравитация выключилась, Земля остановилась, Луна исчезла, интернет пропал,
  все прыгнули, туннель сквозь Землю, проснулся в прошлом с телефоном, стал муравьём.
- Хорошая идея: бытовая и узнаваемая («Wi-Fi видно», «ложь весит грамм»), абсурдная, легко рисуется предметами в комнате/городе,
  провоцирует комментарии («я бы весил тонну»).
- Фантазия разрешена, **но не выдавай выдумку за реальный факт** (без «учёные доказали» и выдуманных цифр).
  Реальные детали — проверяй (WebSearch), в файл сценария пиши раздел «Что правда, что фантазия».
Порекомендуй одну и объясни почему.

## Шаг 2. Сценарий (45–90 с; владелец разрешил длиннее, но «качественно»)
Структура:
1. **Хук-обещание** (≤ 3 с): вопрос/обещание, которое зритель хочет досмотреть («…ты бы узнал, кто ворует твой интернет»).
2. **«Представь…»** — дальше во втором лице, бытовая сцена.
3. **«Ружьё»** — деталь в начале, которая выстрелит в финале (кот на роутере).
4. **Нарастание**: странно → смешно → загадка → масштаб → разоблачение. Новая картинка каждые 1–2 фразы.
5. **Вопрос вслух** на ~40% («Как так?») и **бытовая аналогия** (сосед с перфоратором).
6. **Финал-кнопка ≤ 10 слов**, отвечает на хук и стреляет «ружьём». Без морали и призывов.
Ритм: после длинной фразы — короткая (2–5 слов). Теги ElevenLabs v3: `[excited]` в начале, `[playful]`, `[pause]`, `[chuckling]` в финале.
Посчитай: слова, символы, длительность (слова ÷ 2,0…2,5 ÷ 1,1 после ускорения), кредиты (≈ 1 кредит/символ на Eleven v3).
Покажи текст (блоком для копирования) + раскадровку таблицей (абзац → что в кадре, стиль D/A). Запиши в `project/facts/<slug>/script.md`.
Спроси «Сценарий ок?» и, если ок, попроси сгенерировать голос.

## Шаг 3. Голос (делает владелец)
- Бесплатный тариф ElevenLabs **не даёт библиотечные голоса через API** (ошибка 402) → владелец генерирует на сайте:
  голос **Nikolay**, модель **Eleven v3**, текст с тегами → скачивает mp3 → присылает в чат.
- Не трать кредиты без согласия; называй расход заранее. Бесплатный тариф: без коммерческой лицензии,
  в описании нужна подпись «Voice generated by ElevenLabs» — напоминай перед публикацией.
- Ускорь на 10% без смены тона: `ffmpeg -y -i присланный.mp3 -af atempo=1.1 <P>/public/voice.mp3`. Исходник — в `project/facts/<slug>/voice/`.

## Шаг 4. Проект и тайминги
1. `cp -r .claude/skills/what-if-shorts/template <P>` → `cd <P>` → `npm install` (или `ln -s ../short-black-hole/node_modules node_modules`, если тот есть).
2. `script/voice.txt` — текст с тегами (абзацы через пустую строку), `script/voice_display.txt` — без тегов, числа цифрами.
3. Тайминги: `node tools/whisper.mjs public/voice.mp3 ru` → `audio/words.json`.
   **Облако:** node не скачивает модель через прокси — заранее
   `mkdir -p ~/.doodle-shorts/whisper && curl -sSL -o ~/.doodle-shorts/whisper/ggml-small.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin`
   (если файл 0 байт после неудачи — удалить и скачать curl'ом).
4. `node tools/plan.mjs` → `src/plan.json` (субтитры: слова сценария + время whisper). Начало каждой сцены = время первого слова абзаца.
5. Музыка: `node tools/music.mjs <длина+3> playful` → `public/music.wav`.

## Шаг 5. Сцены — правишь `src/Video.tsx` (набор — `src/brand.tsx`)
- `makeIso(S, CX, CY)` → `I.Room mode`, `I.Cube` (предметы-блоки: x,y,z угол; w,d,h размеры; три цвета граней; `shadow` в D),
  `I.iso / I.pts / I.ring`. Комната 10×10×7, левая стена x=0, правая y=0.
- `Waves` — живые кольца (сигнал, звук, тепло, запах) с клипом по комнате; `Stage mode` — фон + фильтры; `Finish mode` — зерно и виньетка.
- `Cam t0 keys=[[сек, масштаб, x, y]…]` — камера всегда дрейфует, края не открываются, после склейки «посадка».
- `Title` — бирка «А ЧТО ЕСЛИ…» + вопрос (первые ~3 с). `Card mode` — плашка-факт (D — бумажная карточка, A — тёмная неоновая).
- `Captions` — 2 строки: D — на кремовой бумажной полоске, A — белые капсом; сказанное слово в полную силу, будущее 30%,
  слова из `ACCENT` — на розовой подложке (D) / малиновым свечением (A).
- **D** — дневные/бытовые сцены (палитра `D`: крем, тил, коралл, горчица, роза). **A** — ночь, космос, техника, «секретное»
  (палитра `A`: тёмно-синий, голубой неон, малиновый). Смена D↔A — на склейке, лучше по смыслу («свет погас»).
- В каждой сцене 6–12 предметов, один главный «магический» элемент светится. Без людей-персонажей; животные — блоками.
- Каждые 1–2 фразы — новая сцена или заметное событие (появилась плашка, вспыхнуло, обвели маркером).

## Шаг 6. Звук
`script/sfx.json`: `beds` — фоны по сценам (`space|day|night|room`), `events` — `[сек, тип, громкость]`
(`whoosh` на каждой склейке, `pop` на плашках, `tick` для счётчиков, `boom/riser` на кульминации, `chime` в финале …)
→ `python3 tools/sfx.py` → `public/sfx.wav`. Микс в Video.tsx: голос 1.0, музыка 0.22, звуки 0.45 (владелец просил громче, чем было).

## Шаг 7. Проверка и рендер (2D, быстро: ~3 мин на 47 с в полном 1080×1920)
- Шрифты Google грузятся только в **полном Chromium**: `C=/opt/pw-browsers/chromium-1243/chrome-linux64/chrome`
  (headless-shell даёт NetworkError). WebGL/3D не используем — в облаке он рендерится часами.
- Кадры: `npx remotion still src/index.ts Video checks/f.png --frame=<кадр> --browser-executable=$C --scale=0.25` по 1–2 на сцену,
  собери сетку и посмотри: края кадра, текст не перекрывается, субтитры не закрывают главное.
- Рендер: `npx remotion render src/index.ts Video out/video.mp4 --browser-executable=$C --concurrency=4`.
- Громкость: `ffmpeg -y -i out/video.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5:LRA=11 -ar 48000 -c:a aac -b:a 192k out/final.mp4`,
  проверь `ebur128` (≈ −14…−15 LUFS, пик ≤ −1 dB) и `ffprobe` (1080×1920, длительность).
- Скопируй в `<P>/<slug>.mp4`, отправь владельцу (SendUserFile) с подписью «что изменилось / что проверить».
  mp4, wav и node_modules в git не коммить (`.gitignore`), исходники — коммить и пушить в рабочую ветку.

## Чек-лист перед отправкой
- [ ] Хук звучит с 0 с, бирка + вопрос в первые 3 с, первая сцена уже живая.
- [ ] Стиль D (и A где нужно) по `BRAND.md`, нет людей, нет пустых сцен, камера всегда движется.
- [ ] Каждая сцена начинается на первом слове абзаца (±0,2 с), события — на ударных словах.
- [ ] Субтитры = текст сценария, 2 строки, не закрывают главный предмет.
- [ ] Голос разборчив поверх музыки и звуков; итог ≈ −14 LUFS.
- [ ] Не утверждай, что проверил звук на слух или на телефоне — это делает владелец.

## Нельзя
Дудлы и «детская» графика; люди-персонажи; 3D/WebGL; выдумка, поданная как реальный факт; трата кредитов ElevenLabs без согласия;
утверждать, что ролик готов к публикации, пока владелец не проверил звук, права и подпись ElevenLabs.

# Странно, но факт — пакет проекта (v2.3)

Рабочая мультвселенная вертикальных рисованных историй. Публикуется одновременно на YouTube Shorts и VK Клипах. «Странно, но факт» — рабочее название.

## Состав пакета
| Файл | Назначение |
|---|---|
| `PROJECT.md` | Концепция, тон, формат, правила мира и канон, звук, критерии готовности |
| `CHARACTERS.md` | Персонажи, правила непрерывности, промпты листов персонажей |
| `VISUAL_STYLE.md` | Художественное направление, сборка кадра, безопасная зона, субтитры и шрифты, промпты |
| `PILOT_EPISODE.md` | Производственная версия пилота «Квартира № 14»: сценарий, раскадровка с хронометражем, озвучка, звуки, ресурсы, промпты |
| `PRODUCTION_PLAN.md` | **Новый.** Кто что делает, этапы производства, источник изображений, хранение проекта, таблица прав, открытые вопросы |
| `DISTRIBUTION.md` | Мастер-ролик, отдельные публикации для двух площадок, проверенные факты с датой, чек-лист перед публикацией |
| `CLAUDE_INSTRUCTIONS.md` | Инструкция для Claude, включая работу аниматором и монтажёром |
| `CHANGELOG_V2.md` | Что изменено по сравнению с v1 (v2 и v2.1) и почему |
| `v1_original/` | Исходные файлы v1 без изменений — для сравнения |

## Как устроена работа (v2.2)
- **Сторонние монтажные приложения не используются.** Анимацию, монтаж, **озвучку (синтез речи)**, звук, **субтитры** и экспорт делает Claude.
- **Виталя** работает с телефона:
  - утверждает документы, листы и черновики;
  - выбирает голоса на слух по роликам-кастингам;
  - смотрит видео и пишет замечания с таймкодами;
  - публикует ролики.
- **Изображения** приходят от генератора. Каким путём — решается до этапа 1 (`PRODUCTION_PLAN.md`).

## Как использовать
1. В новом чате передай Claude все файлы пакета и, если есть, последний архив проекта (`S01E01_project_vN.zip`).
2. Работай по этапам `PRODUCTION_PLAN.md`. Каждый этап начинается после твоего подтверждения.
3. После каждого этапа сохраняй архив проекта от Claude — рабочая среда Claude временная.
4. После сборки пилота оцени результат и обнови документы, если изменились дизайн или процесс. Изменения записывай в журнал изменений.

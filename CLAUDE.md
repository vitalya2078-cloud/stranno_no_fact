# Инструкции для Claude — канал анимаций про выживание

## Владелец
- Работает **только с Android-телефона**, без компьютера. Всё, что от него нужно, должно делаться с телефона.
- Отвечай по-русски, на «ты», просто и по делу.
- **Ничего не делай без согласования.** Сначала предложи (варианты, эскиз), потом делай — после явного «ок».
- Не переходи к следующему этапу ролика без подтверждения.

## Формат
Вертикальные анимированные ролики про выживание «катастрофа × место», 65–90 с, 1080×1920.
Весь процесс — навык `.claude/skills/survival-shorts/` (этапы, стиль, чек-лист, обложка, правила площадок).
Файлы: `project/survival/channel/` — стиль, герой, собака; `project/survival/episodes/<имя>/` — ролики.

## Ограничения и правила
- Облачная среда: только 2D (Remotion), 3D/Blender не используем. Рендер — в полном Chromium (`/opt/pw-browsers/chromium-1243/chrome-linux64/chrome`).
- Голос — ElevenLabs через сайт (генерирует владелец, присылает mp3). Кредиты не тратить без согласия, расход называть заранее.
  Бесплатный тариф: без коммерческой лицензии, в описании «Voice generated by ElevenLabs».
- Ключи и токены в чат не просить; ключ ElevenLabs — только через «Секреты сети» среды.
- Советы в роликах только безопасные; цифры проверять по источникам.
- Не утверждать, что звук проверен на слух или на телефоне, — это делает владелец.
- Коммиты и push — только в рабочую ветку. Видео, wav и node_modules в git не класть.
